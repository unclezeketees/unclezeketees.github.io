# unclezeke.com

Static site for Uncle Zeke's Place, served by GitHub Pages from `main`.

- `index.html` front page (Red Shirt Wednesday, who we are, store doors)
- `shirts.html`, `minddump.html`, `prints.html`, `books.html` store pages
- `style.css` shared styles
- `img/web/` resized images used by the site (`img/*.png` are the originals)
- `_build/build.py` generates the HTML pages. Edit links and items there, then run `python3 _build/build.py`.
